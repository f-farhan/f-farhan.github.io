title: "A Dual-Pipeline Approach for Colorectal Polyp Detection and
Segmentation with Machine and Deep Learning Models"
description: "The rate of colorectal cancer is growing at an alarming rate all over the world. The survival rate of patients drastically
10decreases when the cancer reaches its final stage. Hence the identification and removal of colon polyps is very important for the patients
11 at early stages. Advanced computer-aided systems can assist polyp detection that outperforms manual detection methods. In this paper
12we present the development of an automated polyp detection system using advanced machine learning and deep learning models. The
13 first pipeline of this work involved classification of polyps using machine learning models and deep learning models. We explored two
14methods of image feature extraction for the machine learning classifiers namely, Local Binary pattern (LBP) and Gray Level Co-
15 occurrence matrix (GLCM). The LBP based feature extraction, with LightGBM classifier gave the best accuracy for polyp classification,
16 achieving 94% accuracy and 93.9% F1-score. In comparison to the machine learning classifier, the deep learning classifier EfficientNetB0
17 achieved up to 96% test accuracy. The second pipeline employed deep learning models for polyp segmentation, with the best model (U-
18 Net with the EfficientNetB0 backbone) achieving up to 90.76% and 72.13% dice coefficients on the validation and test datasets
19 respectively. Overall, we confirmed that the deep learning pipeline gave promising results for both polyp segmentation and classification."
